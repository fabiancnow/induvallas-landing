# Induvallas - Proyecto de Inteligencia de Mercado y Estrategia Comercial (2026)

Este repositorio contiene la arquitectura de negocio, inteligencia de mercado basada en scraping con Apify, matrices de posicionamiento y activos creativos para **Induvallas** (Ecuador).

---

## 📁 Estructura del Proyecto

```text
├── .env                                       # Credenciales de Apify y configuración privada
├── .env.example                               # Plantilla de variables de entorno
├── .gitignore                                 # Protección de secretos y datasets locales
├── README.md                                  # Resumen ejecutivo y bitácora del proyecto
├── data/
│   ├── raw/                                   # Datasets crudos extraídos de Apify

    └── analysis/                              # Scripts de procesamiento de texto y análisis
```

## 🚀 Estado de Avance y Bitácora

### ✅ Semana 1: Arquitectura del Negocio e Inteligencia de Mercado (Completado)
* **Entorno configurado:** Clave de API de Apify verificada para el usuario `fabiannow`.
* **Definición del Negocio:** Nicho OOH/DOOH, modelo B2B High-Ticket corporativo, y perfil del ICP (CMOs, Brand Managers, Directores de Medios).
* **Web Scraping Apify en Vivo:** Extracción de reseñas de Google Maps sobre Induvallas y competidores en Ecuador (Dataset público: [n9SwWQau3HUcqmgbE](https://api.apify.com/v2/datasets/n9SwWQau3HUcqmgbE/items)).
* **Matriz de Fricción vs. Deseo:** 3 Dolores nucleares identificados (Riesgo legal/municipal, Caja negra del ROI, Saturación digital).
* **Creativos TOFU:** 3 Copys PAS estructurados y 2 guiones de video corto (0-30 seg) optimizados para formato vertical.
